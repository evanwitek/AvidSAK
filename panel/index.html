        Maintenance

        Health check

        Read-only. Media Composer details come from the PanelSDK; files, services and drives come from the helper on this machine.

        Media databases

        ScanAvidMediaFilesFolder updates or recreates the PMR and MDB databases. Do this when clips copied onto a drive stay offline.

        Caches and state files

        Media Composer must be quit. Cache folders are renamed with an _old-<timestamp> suffix and rebuilt on next launch; MCState and site setting files are moved to quarantine.

        Avid Attic

        Archive writes a zip to the quarantine folder and verifies it. Archive and clear deletes the project folder only after that zip exists.

        Bins and lock files
        Media folders on disk

        Avid's guidance is 5000 files or fewer per numbered folder. "Split" moves the oldest MXF files into the next numbered folder; nothing is deleted.

        Commands (menu items)

        Command ids are only valid for this launch of Media Composer, so the list is read every time. Anything Media Composer puts in a menu appears here.

        System and console

        The console buttons bring Media Composer to the front and type a fixed command. Media Composer must be idle, not sitting on a modal dialog.

        What this tab cannot fix
        • Licensing: activation, deactivation and dongle updates stay in Avid Link and your Avid account.
        • Judging corrupt media: the tab can play a section (Alt+6) but not decide whether a clip, its media or the sequence is at fault.
        • Server-side repairs: Media Indexer, NEXIS and MediaCentral/Interplay problems need the server administrators.
        • Hardware: failing drives, RAID controllers, switches and cables.
        • Plug-in compatibility: the tab can list installed plugins by date, not decide which one to remove.
